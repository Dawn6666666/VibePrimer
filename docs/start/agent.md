这一章最容易被工具焦虑吞掉。先说结论：**你现在用哪个都行，重要的是你会不会"牵引"它。**

但在那之前，得先分清它和普通 AI 网页版的区别。

## 它不只是"会写代码的聊天框"

| | 网页版 AI（ChatGPT / 豆包 / Kimi） | 编程 Agent（本章要装的） |
| --- | --- | --- |
| 能看你的项目文件吗 | 看不到，你得手动复制粘贴 | 能，它自己在文件夹里读 |
| 能改文件吗 | 不能，只能给你代码让你复制 | 能，直接写进你的文件 |
| 能跑命令吗 | 不能 | 能，`npm install`、跑测试、看报错 |
| 出错之后 | 你再描述一遍 | 它自己看到报错，自己改 |

最后一行是关键。**能自己跑、自己看报错、自己再改**——这才叫 Agent。你和它之间不再是"复制粘贴"，而是"你下指令，它动手，你验收"。

代价是：它有权限改你的文件。所以 Git（[上一章](/start/git/)）必须先装好。

## 三条路线，按你的条件选

手机号注册，国内直连，免费额度够你把这份指南走完。中文界面，内置国产模型。

**适合**：没有国际网络、没有外币卡、想马上开始。

<Card title="路线二 · 学生认证" icon="carbon:education">

**GitHub Copilot（学生免费）**

用学校邮箱做 GitHub 学生认证，Copilot Pro 免费用。顺手把 GitHub 账号也注册了。

**适合**：有学校邮箱，愿意花二十分钟做认证。

</Card>

<Card title="路线三 · 进阶" icon="carbon:rocket">

**Claude Code / Codex CLI**

终端里的 Agent，Plan Mode、项目规则文件、hooks 这套工作流最完整。需要国际网络 + 外币支付（约 $20/月）。

**适合**：有订阅，想提前学会职业工作流。

</Card>

三条路线都能走完这份指南。后面的截图和示例，多数是路线三的界面，但**指令内容完全通用**——你换成"先别写代码，给我计划"在任何工具里都成立。

## 路线一：VS Code + Trae

Trae 国内版（`trae.cn`）本质是一个装好了 Agent 的 VS Code。不想换编辑器的话，用插件版也行。

:::: steps

1. **下载**

   打开 [trae.cn](https://www.trae.cn/)，下载 Windows 或 macOS 版，手机号注册。

2. **导入你的 VS Code 配置（可选）**

   首次启动会问要不要导入 VS Code 的设置和快捷键，选导入。这样你 [上一章](/start/vscode/) 调好的东西不用重来。

3. **打开文件夹**

   `文件 → 打开文件夹`，选中你的 `vibe-lab`。**不要打开单个文件**——Agent 看不到旁边的文件，就只能瞎猜。

4. **切到 Agent 模式**

   右侧面板默认可能是 Chat（只聊不改）。找到模式切换，选 **Builder / Agent**，它才有权限读写文件。

5. **给它一个测试任务**

   ```text
   在当前文件夹新建一个 hello.html，里面只有一行 <h1>Agent 能改文件</h1>。
   不要做别的。
   ```

   文件真的出现在左边树里 → 装好了。

::::

::: tip 同样的事，插件版怎么做
不想换编辑器：VS Code 扩展市场搜 **通义灵码**（阿里，国内直连，已被并入 Qoder 品牌，免费基础版仍在）或 **Cline**（开源插件，可以接自己的模型 API）。

插件版的能力边界和 IDE 版差不多，缺点是界面窄、多文件操作不如 IDE 顺手。
:::

## 路线二：GitHub Copilot（学生免费）

:::: steps

1. **注册 GitHub**，然后去 [education.github.com](https://education.github.com/) 申请 Student Developer Pack。需要学校邮箱，有时还要学生证照片。审核几小时到几天。
2. 认证通过后，Copilot Pro 在账号里是免费开通的（额度政策每年都在改，以页面为准）。
3. VS Code 里装 **GitHub Copilot** 扩展，登录 GitHub 账号。
4. 打开 Copilot Chat 面板，把模式切到 **Agent**（不是 Ask），它才能改文件。

::::

Copilot 的强项是和 VS Code 贴得紧、代码补全最顺。弱项是"一次做一整块任务"时，不如专门的 Agent 稳。用来走这份指南够。

## 路线三：Claude Code 或 Codex CLI

两个都是终端里的 Agent。装好之后，在项目文件夹里敲 `claude` 或 `codex`，就进了一个能读写文件、能执行命令的对话。

```bash
# 以 Claude Code 为例（需要 Node.js 18+，或用官方安装脚本）
npm install -g @anthropic-ai/claude-code
cd vibe-lab
claude
```

进去之后先记住两个键：

- `Shift+Tab` → 切 **Plan Mode**：它只能读文件和思考，不能改文件。**你这门课一半的时间应该在这个模式里。**
- `/clear` → 清空对话。聊久了它会变笨（见 [上下文](/craft/context/)）。

::: warning 别把额度交给运气
按量计费的 API key 是最危险的一种：你让它"跑一个无限循环的优化"，一晚上能烧掉几百块。

- 用订阅制（月付），不要用裸 API key 跑长任务
- 在服务商后台设一个消费上限
- 看到"按 token 计费"四个字，先估一次成本再按回车
:::

## 装好之后，先做这三件事

不是功能测试，是**建立正确的默认姿势**：

1. **永远在项目根目录启动它。** 它在哪个目录启动，就只看得见那个目录里的东西。
2. **第一句永远是"先别写代码"。** 让它读、让它说、让它给计划。你批准了它才动手。
3. **它能改文件，所以你必须能回滚。** 每次让它动手之前，`git status` 确认工作区是干净的。

## 别让它做的事

| 别让它 | 为什么 |
| --- | --- |
| 一次改 5 个文件 | 你审不过来，出问题也定位不了 |
| 装你没听说过的依赖 | AI 会推荐不存在的包，见 [安全](/craft/safety/) |
| 读你的 `.env` | 里面是 key，贴进对话就等于泄露 |
| 访问学校内网、你的私人文件夹 | 权限给到项目文件夹为止 |
| 直接 push 到 GitHub | 让它改完，你自己看 diff，自己提交 |

## 工具会变，工作流不会

你可能会换五次工具。每次换的时候你都会觉得"这个更强"——它确实更强，但你的能力没变。

真正会留下来的东西是：**怎么把一个模糊想法拆成可验收的小块、怎么判断输出对不对、怎么在它跑偏时把它拽回来**。这三件事，换成任何工具都通用。
