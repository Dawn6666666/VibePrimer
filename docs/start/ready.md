## 装不上怎么办

下面三类占了新手环境问题的一大半。出现了先看这张表，别急着让 AI 改代码——它不知道你电脑上装了什么。

::: collapse

### 1. `code .` 提示找不到命令

Windows：重新跑一次安装包，选「修改」，把 **添加到 PATH** 勾上，装完**重开终端**（旧终端不会读到新 PATH）。

macOS：VS Code 里 `Cmd+Shift+P` → 输入 `shell command` → 选 **Shell Command: Install 'code' command in PATH**。

### 2. `npm` 提示找不到命令

说明 Node.js 没装。去 [nodejs.org](https://nodejs.org/) 下 LTS 版，装完**重启终端**，再 `node -v` 和 `npm -v` 各敲一次。

macOS 用 Homebrew 更省事：`brew install node`。

如果只有 `npm` 找不到而 `node` 正常，可能是安装时没勾 npm——重装一次最省时间。

### 3. Agent 建不了文件 / 说没权限

三个可能，按顺序排：

1. **你打开的是单个文件，不是文件夹。** `文件 → 打开文件夹`，选整个项目目录。
2. **你用的是 Chat 模式，不是 Agent 模式。** Chat 只能聊天，改不了文件。
3. **终端启动时不在项目目录。** `cd` 到项目文件夹再启动，或者先 `pwd` 看一眼。

排查顺序就按这个来，90% 是第一条。

:::

## 建一个实验文件夹

接下来所有练习都放这一个地方，别散在桌面上：

```text
C:\dev\vibe-lab\          ← Windows 举例，macOS 用 ~/dev/vibe-lab
├── pomodoro\             ← 案例一
├── schedule\             ← 案例二
└── notes.md              ← 随手记：踩过的坑、prompt 片段
```

两个规矩：

- **路径不带中文、不带空格。** 就这一条能省你两小时。
- **一个项目一个文件夹，各自 `git init`。** 不要把两个项目塞进一个仓库。

`notes.md` 别小看。你会发现自己同一个坑踩三次——写下来就不容易踩第四次。把常用的提示词片段也贴进去，比每次重新想要快。

## 环境问题的一个态度

::: tip 别硬扛，先让它跑起来
环境问题有个特点：**它们和你要学的东西没关系**。你不会因为解决了 `PATH` 问题而更懂编程，但你会在那上面耗一下午，然后放弃整个计划。

所以：卡超过 30 分钟，就换一条路。用 Trae 代替 VS Code，用本地文件代替 Git 远程，用最简单的单文件 HTML 代替需要构建的项目。**先让东西跑起来，环境可以后面再补。**

反过来，靠"环境没装好"当借口不开始，是另一种形式的拖延。
:::
