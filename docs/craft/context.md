你大概已经遇到过：下午两点你确认过"不要用框架"，五点它给你 `import React from 'react'`。你翻上去找那句话，它还在那儿，白纸黑字。

它没瞎。是它已经**看不全**了。

## 一个硬事实

2025 年 Chroma 做过一个实验：拿 18 个前沿模型，喂不同长度的输入，测同一批任务。结论很一致——**输入越长，表现越差**，而且不是缓慢下降，是在信息变多之后明显掉档。另一份研究（Lost in the Middle）更具体：关键信息放在长上下文的**中间**时，最容易被忽略。

对你的意义：

- 上下文窗口不是"能装多少就装多少"，装得越满，它越抓不住重点
- 中间那段最危险。你最早说的需求、中途确认的约束，正好都在中间
- 这不是"AI 不行"，是所有长上下文模型的共性。**你要学会给它干净的上下文。**

## 三个信号：该开新会话了

| 信号 | 具体表现 |
| --- | --- |
| 重复问 | 它重新问你"这个项目用什么技术栈？"——十分钟前你答过 |
| 重复改 | 它开始改一处你已经改好的地方，或者把修好的 bug 改回来 |
| 想重写 | 它说"让我重新实现整个文件"、"我重写一下这部分" |

出现任意一个，别辩论，别纠正第三遍。**收尾，开新会话。**

::: warning 同一个错误纠正两次就该重开
第一次纠正：可能你描述不清。
第二次纠正：可能是上下文里混了矛盾信息。
第三次纠正：你在浪费时间。它已经陷在这个错误假设里，你越解释，那个假设在上下文里占的比重越大。

**新会话不是认输，是清场。**
:::

## 四个动作

### 一、一个任务一个会话

会话的边界不是"一天"，是"一件事"。

- 做番茄钟的计时逻辑：一个会话
- 加刷新保持：可以接着，也可以新开
- 换去做课程表：一定新开

聊完一个阶段，`/clear`（或新建对话）。你会明显感觉到它变利索了。

### 二、把结论落到文件

上下文会丢，磁盘不会。每完成一个阶段，让关键信息变成文件：

```text
SPEC.md      需求和验收标准（你写的，它只读）
TODO.md      任务清单，做完的打勾
AGENTS.md    项目规矩：怎么跑、不许做什么
BUGS.md      踩过的坑，一句话一条
```

新一轮开始时，第一句就是：

```text
先读 SPEC.md、TODO.md、AGENTS.md，然后告诉我你现在理解的
项目目标、当前进度、下一步该做什么。先不要改代码。
```

这三句话能替代你重新解释半小时。

### 三、重要约束，重复在当前消息里

不要指望"我前面说过了"。把这句话当成习惯：

```text
（重申：单文件、不用框架、不装依赖。）
```

一行字，省掉一次返工。丑，但有效。

### 四、喂文件要挑，不要倒

它读整个项目不是免费的：慢、贵、还稀释重点。

| 别这样 | 这样 |
| --- | --- |
| 把整个仓库贴进去 | 只给相关的那一个文件 |
| 贴 800 行说"你看看" | 贴第 20–60 行，说"问题在这段" |
| 让它"读一下项目" | 让它先读 README 和目录，再决定读哪个文件 |

## 项目规矩文件

这是最划算的一件事：写一次，之后每次会话它都自动读到。

在项目根目录建 `AGENTS.md`（Claude Code 叫 `CLAUDE.md`，Cursor 用 `.cursor/rules`，本质一样）：

```markdown
# 项目规矩

## 这是什么
一个本地番茄钟，单文件 index.html，双击打开就能用。

## 怎么跑
双击 index.html。没有构建步骤，没有依赖。
（如果有构建：`npm install && npm run dev`，端口 5173）

## 硬约束
- 不用任何框架和依赖，不引入 npm 包
- 所有代码写在 index.html 里，不拆文件
- 不修改 <body> 里已有的 id 和 class 名

## 代码风格
- 原生 JS，用 const/let，不用 var
- 状态集中在一个 state 对象里
- 每次改动后必须能双击打开且控制台无报错

## 现在别做
- 不要加新功能，先修 TODO.md 里的问题
- 不要顺手重构、不要改格式
```

三十行，能挡掉一半的"它顺手改了别的东西"。

## 新会话的开场模板

存进备忘录，每次粘贴：

```text
先读 AGENTS.md 和 TODO.md，不要改代码。
用三句话告诉我：这个项目的目标、当前进度、下一步。
等我确认后，只做那一步。
```

## 一条底线

::: tip 上下文是你的资源，不是它的
你怎么整理桌面，就怎么整理上下文。今天做什么、上次到哪、什么不许动——这些信息如果只在对话里，就等于没有。

写下来。文件是你的第二个大脑，也是它的。
:::
