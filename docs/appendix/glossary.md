一个词一句话，加一句「在你项目里它指什么」。

看不完也没关系。**遇到看不懂的词，回来查这一个。**

## A · 提示与模型

::: field-group

::: field Agent（智能体）
@type 名词

能读你的文件、改你的文件、跑命令、看报错的那种 AI。和网页聊天框的区别就这四条。

在你项目里：帮你写代码的那个窗口。
:::

::: field 上下文（Context）
@type 名词

模型这一次对话能"看见"的全部内容：你的话、它的话、读过的文件、跑过的输出。

在你项目里：聊得越久，前面的内容会被挤掉或被稀释——这就是为什么长任务要 `/clear`。
:::

::: field 上下文腐坏（Context rot）
@type 名词

输入越长，模型对其中信息的利用越差。不是"记不住"，是"抓不住重点"。

在你项目里：一个文件聊到 2000 行还硬聊，它开始改错地方。换会话，把现状写成一段话重新开始。
:::

::: field 幻觉（Hallucination）
@type 名词

模型编出一个看起来完全合理、实际上不存在的东西。最典型的是编造包名。

在你项目里：`npm install` 报 404 的那个包，八成是它编的。全球统计里，约五分之一的建议包名并不存在。
:::

::: field 提示词（Prompt）
@type 名词

你发给模型的那段话。不是咒语，是需求描述。

在你项目里：写得好不好，看你有没有说清「什么算做完」。
:::

::: field 系统提示词（System Prompt）
@type 名词

在你说第一句话之前，产品方已经塞进去的一段规则。

在你项目里：它决定了这个工具默认怎么说话、能不能改文件。你改不了它，但可以知道它存在。
:::

::: field Token
@type 名词

模型处理文本的计量单位。一个汉字大约 1–2 个 token，一个英文单词大约 1 个。

在你项目里：额度、价格、上下文长度都按它算。
:::

:::

## B · 代码与版本

::: field-group

::: field 仓库（Repo）
@type 名词

一个被 Git 管着的文件夹。

在你项目里：`git init` 之后，你的项目文件夹就是一个仓库。
:::

::: field 提交（Commit）
@type 名词

给当前状态拍一张快照，附一句说明。

在你项目里：改坏了的退路。一次提交对应"一件做完的事"。
:::

::: field diff
@type 名词

两个版本之间的差异，`+` 是新增，`-` 是删除。

在你项目里：每一次接受 AI 的改动之前，你该看的那一屏。
:::

::: field 依赖（Dependency）
@type 名词

你的项目要用到的别人写的代码包。

在你项目里：`package.json` 里那串名字。每多一个，就多一个可能坏掉的地方。
:::

::: field 构建（Build）
@type 名词

把源码变成能直接运行的东西的那一步。

在你项目里：这两个案例都没有构建——双击就能跑。这是有意的。
:::

::: field 静态站点（Static Site）
@type 名词

不需要服务器算，浏览器拿到文件就能显示的网站。

在你项目里：你的课程表就是。所以它能白嫖 GitHub Pages。
:::

:::

## C · 前端与数据

::: field-group

::: field DOM
@type 名词

浏览器里那棵树，每个标签是一个节点。JS 改的就是它。

在你项目里：`innerHTML` 一赋值，整棵子树就换了。
:::

::: field 事件（Event）
@type 名词

用户做了一件事（点击、输入、按键），浏览器发出的通知。

在你项目里：`onclick` 后面那个函数。
:::

::: field 状态（State）
@type 名词

会变、而且要影响画面的那些数据。

在你项目里：番茄钟的 `remain`、课程表的 `week`。**状态放在一个地方，画面从它算出来。**
:::

::: field 渲染（Render）
@type 动词

把数据变成屏幕上的东西。

在你项目里：`render()` 函数。它只该读数据、生成 HTML，不该在里面做判断。
:::

::: field localStorage
@type 名词

浏览器给你的一个小抽屉，存字符串，关掉浏览器还在。

在你项目里：番茄钟的完成数、课程表的周次。**拿出来全是字符串**，数字要 `parseInt`。
:::

::: field JSON
@type 名词

一种文本格式，长得像 JS 的对象和数组，但键必须加引号。

在你项目里：`localStorage` 存复杂数据时要先 `JSON.stringify`，取出来要 `JSON.parse`。
:::

::: field rowspan
@type 名词

HTML 表格里"这个格子纵向占几行"。

在你项目里：连上两节的课，`rowspan="2"`。占了的格子不能再输出 `<td>`。
:::

:::

## D · 工程习惯

::: field-group

::: field 重构（Refactor）
@type 动词

不改行为，只改结构。

在你项目里：把 `render` 里的判断挪到 `buildColumns` 里。做完之后，页面应该一模一样。
:::

::: field 边界情况（Edge Case）
@type 名词

正常输入之外的输入：空、超长、零、负数、重复点击、断网。

在你项目里：第四节那四个 bug，全是边界情况。
:::

::: field 回归（Regression）
@type 名词

修好 A 的时候把 B 弄坏了。

在你项目里：为什么每次只改一处、改完跑一遍验收——就是为了抓它。
:::

::: field 最小可运行（MVP）
@type 名词

能验证核心想法的最小版本。

在你项目里：番茄钟的第一版没有暂停。它不完整，但它能跑。
:::

::: field Vibe coding
@type 名词

2025 年 2 月 Andrej Karpathy 造的词：不看代码、全部接受、凭感觉往前推。他自己说适合周末玩具项目。

在你项目里：**这是起点，不是终点。** 玩具可以这么玩，作业不行。
:::

::: field Vibe engineering
@type 名词

Simon Willison 提出的对照词：一样用 AI 生成，但规格、测试、审查、版本控制一样不少。

在你项目里：这两章教你做的，就是这个。
:::

::: field 规格驱动（Spec-driven）
@type 名词

先写规格（要什么、什么算完），再让 AI 按规格生成，最后按规格验收。

在你项目里：REQUIREMENT.md + 验收标准 + TODO.md。
:::
