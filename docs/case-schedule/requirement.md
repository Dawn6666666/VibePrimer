课程表首先要决定一门课需要记录哪些信息，以及不同周次和冲突怎样表示。字段没定好就写界面，后面往往要同时修改数据、渲染和样式。

## 先访谈数据和使用规则

在 `schedule` 项目里输入：

```text
我要做一个本地课程表网页，双击打开，课程放在一个数据文件里。
先不要写代码。请问我最多 8 个问题，一次列完。
只讨论课程字段、取值范围和数据的使用规则，不讨论颜色、字体和动效。
```

这个冲突规则是入门版的明确取舍。后录入的冲突课程不会单独占一个格子，但会保留在数据数组和警告文字里。如果以后要求同一格堆叠显示多门课，需要修改布局和验收标准。

## 保存需求卡

新建 `REQUIREMENT.md`，把下面的需求和后面的字段表、验收标准一起保存。后文会让 Agent 直接读取这个文件。

```markdown
# 课程表需求卡

## 使用者与场景
我自己早上出门前查看课程，选课时核对时间。示例有十门课，之后替换成自己的课表。

## 输入
直接维护 data.js；页面只提供上一周和下一周按钮。

## 输出
- 周一至周五五列，第 1–6 节六行
- 连续课程使用 rowspan 合并
- 单双周课程随周次变化
- 冲突课程按数据顺序优先显示并标红，警告列出所有冲突课程对

## 约束
- 双击 index.html 运行，无框架、无构建、无外部依赖
- 课程数据独立放在 data.js
- 周次为 1–20，刷新后保留
- 375px 视口下仅表格容器横向滚动，页面本身不横向溢出

## 本版不做
网页增删改、起止周、课程详情、教务导入和自动计算当前周。
```

四个运行文件指 `index.html`、`style.css`、`data.js` 和 `app.js`。需求文档、TODO 和 README 不计入其中。

## 数据结构

```js
// data.js
const COURSES = [
  { name: '高等数学 A(2)', teacher: '王', room: 'B203', day: 1, start: 1, span: 2, weeks: 'all' },
  { name: '线性代数', teacher: '孙', room: 'B101', day: 3, start: 1, span: 2, weeks: 'odd' },
  { name: '大学物理', teacher: '周', room: 'B101', day: 3, start: 1, span: 2, weeks: 'even' },
];
```

本案例使用两个普通 `<script>` 标签，先加载 `data.js`，再加载 `app.js`。这样与双击打开的目标一致。`export` / `import` 的 ES 模块在 `file://` 下可能受到浏览器本地模块加载限制，本版不采用。

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `name` | 字符串 | 课程名，按普通文本转义后显示 |
| `teacher` | 字符串 | 老师姓名或匿名简称 |
| `room` | 字符串 | 教室或地点 |
| `day` | 整数 | 1–5，周一到周五 |
| `start` | 整数 | 1–6，开始节次 |
| `span` | 整数 | 至少 1，且 `start + span - 1 <= 6` |
| `weeks` | 字符串 | 只能是 `all` / `odd` / `even` |

建议七项都写全。程序可以把漏写的 `span` 当作 1 来容错，但 `span: 0`、越界位置和未知的 `weeks` 值应跳过并调用 `console.warn`，不能在不同函数里各自猜测含义。

老师和教室写错通常不会触发程序报错，所以仍要对照原始课表逐门核对。课程文本即使包含 `<`、`&` 等字符，也应按文本显示，不能直接当成 HTML 执行。

## 为什么这样存

`day` 和 `start` 使用数字，便于计算列和行；数组下标从 0 开始，所以渲染时用 `day - 1`、`start - 1` 做一次转换。

`span` 可以直接用于 HTML 的 `rowspan`。如果存结束节，就要额外计算 `end - start + 1`。两种结构都能用，本版选择更接近渲染需求的一种。

`weeks` 的三个字符串值覆盖本版全部需求。以后出现“1–16 周”课程时，需要扩展成起止周或周次列表，不能直接把它当作 `all`。

## 验收标准

| # | 操作 | 预期结果 |
| --- | --- | --- |
| 1 | 清除本页保存的周次后打开 | 默认第 1 周，表头周一至周五，左侧 1–6 |
| 2 | 在第 1、2 周分别对照原始课表 | 十门课的数据记录正确；应上课的课程显示或出现在冲突警告中，单双周互补课不同时出现 |
| 3 | 查看高等数学等连上两节的课程 | 一个格子跨两行，下一行不重复输出课程格 |
| 4 | 查看周三第 1 节并切周 | 第 1 周是线性代数，第 2 周同格是大学物理 |
| 5 | 切到第 2 周并刷新 | 仍显示第 2 周 |
| 6 | 查看周四第 5 节 | 先录入的课程标红，警告包含两门冲突课名，并写“1 对课程冲突” |
| 7 | 开发者工具设为 375px | 表格容器可横向滚动，页面本身不左右溢出 |
| 8 | 在 `data.js` 添加一门合法且不冲突的课程 | 刷新后出现，其他运行文件不用改；验完删除测试课程并刷新 |

添加课程后如果白屏，先记录 Console 的实际报错，不要预设只有一种原因。逗号、引号、脚本加载顺序和字段校验都可能导致类似现象。
