## 实战小结

回顾这次使用终端 `pi` CLI 配合开发课程表的过程，主要经验如下：

:::: card title="协作要点小结"
1. **终端交互直接**：通过 CLI 配合，工具调用与终端执行流程紧凑，易于结合 tmux 等工具在后台持久化运行。
2. **先定数据结构**：在涉及多字段的场景下，先明确数据结构与字段范围，编写界面渲染时就能减少反复修改。
3. **考虑边界异常**：例如在处理 `rowspan` 和时段冲突时，提前约定冲突处理规则，避免表格错位。
4. **控制单次改动范围**：派发任务时明确边界，每次只做一个独立任务，便于审查与验证。
::::
